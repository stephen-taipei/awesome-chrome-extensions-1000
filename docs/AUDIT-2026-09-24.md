# Codebase audit — 2026-09-24

## Decision and scope

**This is a collection of examples and prototypes, not 965 production-certified extensions.**
The repository name describes a target of 1,000. The audited snapshot contains **965 Manifest V3 packages**.
The root category/landing page `index.html` is preserved byte for byte; its SHA-256 is
`a64d3e114fa2276b3d1353e50411137fd9076652147cfc63261bafa4629a6fef`.

Source snapshot: `d45c02112c6a03543fdf3374c3d8aaa90d74b142` (the initial audit workflow commit;
its parent contains the original application code). Repairs are intentionally reproducible with
`python scripts/repair_legacy.py --apply`; the default mode is read-only.

Coverage: every extension manifest, declared package resources, extension HTML, PNG integrity,
JavaScript syntax and selected risky source patterns. Manual fixes and behavior tests focus on
password generation, CSP-blocked copy controls, update-time storage initialization, Math Quiz and
Auto Refresh. A static pass does **not** verify every advertised feature, browser permission, website
integration, accessibility criterion, Web Store policy or possible injection path.

## Confirmed findings and disposition

| Priority | Finding before repair | Change | Remaining limitation |
| --- | --- | --- | --- |
| P1 | 221 unique missing icon paths in 87 packages; another 1,158 PNG files have invalid CRCs | Generate valid package-local 16/48/128 PNG fallbacks only for missing/corrupt images | Fallback artwork is neutral, not a custom brand design |
| P1 | 386 identical UI stubs falsely return “Action completed” and interpolate stored data into HTML | Label all as **Prototype — functionality not implemented**, disable the action, remove unused background registration and storage permission, stop reading old data | These 386 advertised tools remain **unimplemented**; old storage is not erased |
| P1 | #222 Password Generator uses `Math.random()` for secrets | Web Crypto with unbiased rejection sampling, length validation, selected-character coverage, all-unchecked error and clipboard error states | No password-vault or password-strength certification |
| P1 | #974 defaults overwrite settings on updates; weak four-word phrases are labeled strong | Install-only initialization, validated request boundary, packaged crypto helper, default 16-word passphrases, explicit dictionary-size entropy disclosure | The fixed 24-word dictionary needs 16 words for about 73 bits; use a larger reviewed dictionary for shorter memorable phrases |
| P1 | 21 experimental background initializers overwrite stored defaults on extension update | Guard default writes with the install reason while retaining other event registration | Broader concurrent-storage behavior is not universally audited |
| P1 | #013 Auto Refresh uses service-worker `setInterval`, loses its schedule on suspension and has competing popup/background storage writes | Single-owner serialized worker state, `chrome.alarms`, session storage, alarm reconciliation, tab/origin validation and error responses | Minimum 30 seconds; browser scheduling can be delayed; stops on browser restart, tab close or cross-origin navigation |
| P2 | 33 executable inline copy attributes in 30 developer-tool packages are blocked by MV3 CSP | External delegated click/keyboard listeners; attribute-safe `data-copy`; visible success/error status | Clipboard availability still depends on browser policy and focus |
| P2 | 23 inline image-error handlers in 20 productivity files, two blocked pages with inline scripts, one inline Back button | External package scripts and event listeners | Third-party favicon/privacy practices elsewhere require follow-up |
| P2 | 183 text escaping helpers fail to escape quotes used in attributes | Consistent null-safe escaping of text and both quotes | This does not make arbitrary URL, CSS or JavaScript contexts safe |
| P2 | Syntax errors in #519 Phrase Builder and #999 Ultimate Toolbox | Repair string quoting and unmatched closure; parse every JavaScript file | Parsing is not functional testing |
| P2 | #317 Math Quiz relies on CSP-blocked `eval`, permits repeated scoring, and races the end timer | Direct arithmetic, one answer per question, strict numeric input, deadline-based timer, guarded delayed callbacks | Other games remain outside targeted behavior coverage |
| P2 | `commands`/`windows` incorrectly declared as permissions in four manifests | Remove the four invalid declarations | Other permissions still need purpose-by-purpose review |
| P2 | No executable repository-wide quality gate; README describes planned folders as present | Add Python static audit, Node syntax and regression tests, browser smoke tests, inventory and honest implementation status | CI gates cannot certify all 965 products |

## Reproducible validation

No npm install is needed for core checks. Use Node.js 22+ and Python 3.11+.

```sh
python scripts/audit.py --json .audit-results.json
node --experimental-vm-modules scripts/check-syntax.mjs
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
python scripts/repair_legacy.py  # read-only: changed_files must be 0 after repair
```

At repair authoring time: **965 manifests**, **969 HTML files**, **2,765 PNG files**,
**1,456 JavaScript files**, **0 structural gate errors**, **386 explicitly unimplemented prototypes**.
Core regression coverage comprises **10 Python tests and 16 Node tests**.
The original structural scanner returned 1,570 error records; this includes duplicate references to
the same missing icon and must **not** be presented as 1,570 distinct security vulnerabilities.

Browser suite (development dependency only):

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install --with-deps chromium
python tests/browser_smoke.py --native --json browser-results.json
```

The suite loads the 30 migrated copy-control packages plus representative prototype, password,
quiz, password-worker and auto-refresh packages. Clipboard transport is stubbed to inspect exact
copied data; copy UI, DOM serialization, keyboard interaction and native extension CSP remain real.
Native password-worker messaging is exercised; timing and storage failure boundaries additionally
use deterministic Node API doubles. Native integration results are recorded in CI artifacts.
The authoring container's browser blocks extension and localhost navigation by administrator policy;
no native browser pass is claimed from that container. A hosted CSP mode also exists for local debugging,
but it mocks Chrome storage and is explicitly not a native extension test.

## Implementation inventory and release follow-up

`python scripts/audit.py --json docs/extension-status.json` produces package-level status and
host-permission review entries. The inventory uses only `prototype` and `example-needs-functional-review`;
there is deliberately no inferred `production-ready` label.

Highest-value follow-up work, in order:

1. Implement or remove the 386 prototypes one feature at a time, each with an acceptance test. Do not
   submit or market them as functioning Chrome Web Store extensions.
2. Review the seven broad-host-permission packages against concrete user gestures; replace blanket
   access with `activeTab` or optional host access only when functionality permits it.
3. Trace untrusted data to remaining HTML/URL/CSS sinks. The inventory contains 429 JavaScript files
   mentioning `innerHTML`; this is a triage signal, not 429 proven vulnerabilities. Test imported JSON,
   page titles, favicons, bookmarks, feeds and attacker-controlled URLs.
4. Expand real-browser coverage to storage migrations, quota failures, keyboard/screen-reader use,
   unsupported pages, content-script injection, offline behavior and worker suspension for all packages.
5. Reconcile historical plan IDs/categories with the actual folders, pin CI actions to reviewed commit
   SHAs, define release ownership and automate packaging without including repository-level secrets.
