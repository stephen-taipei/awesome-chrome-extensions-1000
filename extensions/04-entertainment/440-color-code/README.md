# Color Code

A Mastermind-style color code breaking game.

## Features
- 6 colors, 4-peg secret code
- 8 attempts to crack the code
- Hint system (green = correct position, yellow = wrong position)

## How to Play
1. Select a color from the palette
2. Click pegs to place colors
3. Submit your guess
4. Use hints to deduce the secret code!
