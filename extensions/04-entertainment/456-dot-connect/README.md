# Dot Connect

A Chrome extension game where you connect numbered dots in sequential order to form patterns.

## Features
- Progressive difficulty with more dots each level
- Visual feedback for connected dots
- High score tracking via chrome.storage.local
- Dark theme with gradient UI

## How to Play
1. Click on dots in numerical order (1, 2, 3...)
2. Complete the pattern to advance to the next level
3. Each level adds more dots to connect

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
