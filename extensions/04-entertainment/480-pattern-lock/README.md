# Pattern Lock

Remember and reproduce patterns!

## Features
- Simon-says style memory game
- 3x3 grid of nodes
- Patterns get longer each level
- Best level tracking

## How to Play
1. Press Start to begin
2. Watch the pattern light up
3. Repeat by clicking nodes
4. Patterns grow longer as you progress

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
