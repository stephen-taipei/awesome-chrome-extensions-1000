# Bounce Ball

Keep the ball bouncing as long as possible by moving your paddle.

## Features
- Mouse-controlled paddle
- Progressive speed increase
- Power-ups (paddle grow, slow ball)
- High score persistence

## How to Play
1. Move mouse to control the paddle
2. Keep the ball bouncing
3. Collect power-ups for bonuses
4. Ball speeds up every 5 bounces

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
