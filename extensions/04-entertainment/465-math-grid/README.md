# Math Grid

Fill in the grid so that each row and column sums to the correct total.

## Features
- Logic-based number puzzle
- Progressive difficulty levels
- Some numbers revealed as hints
- High score tracking

## How to Play
1. Look at the target sums for rows and columns
2. Fill in the empty cells with numbers 1-9
3. Each row and column must add up correctly
4. Click Check Solution to verify

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
