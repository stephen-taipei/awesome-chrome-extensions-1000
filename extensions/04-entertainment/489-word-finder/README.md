# Word Finder

A classic word search puzzle game.

## Features
- Find hidden words in the letter grid
- Words can be horizontal, vertical, or diagonal
- Click and drag to select letters
- Progress tracking with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Look at the words to find above the grid
2. Click and drag across letters to select
3. Release to check if you found a word
4. Find all words to complete the puzzle
5. Words can be forwards or backwards

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Word search logic
