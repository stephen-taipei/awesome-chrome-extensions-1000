# Grid Fill

A knight's tour puzzle - fill the entire grid using L-shaped moves.

## Features
- 5x5 grid puzzle
- Knight move pattern (L-shape)
- Valid move highlighting
- Progress tracking

## How to Play
1. Start from the knight (♞) position
2. Click on highlighted cells to move
3. Move in L-shapes (like chess knight)
4. Fill all 25 cells to win!
