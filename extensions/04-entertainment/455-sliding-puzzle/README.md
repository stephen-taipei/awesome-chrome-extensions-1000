# Sliding Puzzle

The classic 15-puzzle game - arrange tiles in numerical order!

## How to Play

1. Click "Shuffle" to scramble the tiles
2. Click tiles adjacent to the empty space to slide them
3. Arrange numbers 1-15 in order, left to right, top to bottom
4. Try to solve in as few moves as possible

## Features

- Classic 4x4 sliding puzzle
- Move counter
- Best score tracking with chrome.storage
- Tiles highlight green when in correct position
- Smooth slide animations
- Green/teal gradient theme

## Tips

- Work on getting the top row correct first
- Then work row by row
- The last two rows can be tricky!

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Game interface
- `popup.css` - Styling with dark theme
- `popup.js` - Game logic
