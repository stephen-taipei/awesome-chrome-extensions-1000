# Word Bomb

Type words before the bomb explodes!

## Features
- Fast-paced typing challenge
- Timer decreases as you score
- High score tracking
- Explosive animations

## How to Play
1. Click Start Game
2. Type the displayed word quickly
3. Beat the timer before it explodes
4. Each word adds points, timer gets shorter

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
