# Color Wheel

A colorful spinning wheel game where you match colors.

## Features
- Spin the wheel and land on the target color
- Streak multiplier for consecutive matches
- Smooth spin animation with easing
- High score tracking with chrome.storage.local
- Dark theme with colorful accents

## How to Play
1. Look at the target color displayed above the wheel
2. Click "SPIN" to spin the wheel
3. Match the target color to score points
4. Build streaks for bonus multipliers
5. Miss and your streak resets

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Wheel spinning logic
