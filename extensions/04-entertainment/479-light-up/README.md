# Light Up

Light up all cells in the grid puzzle!

## Features
- Lights Out style puzzle
- Click toggles adjacent cells
- Increasing grid sizes
- Level progression saved

## How to Play
1. Click a cell to toggle it and neighbors
2. Light up all cells to win
3. Grid grows with levels
4. Find the optimal solution

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
