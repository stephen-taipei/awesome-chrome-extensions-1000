# Shape Stack

A stacking game where precision is key - build the tallest tower!

## How to Play

1. Click "Drop!" or press Space to start
2. A shape moves back and forth at the top
3. Time your drop to stack on the previous shape
4. Misaligned drops make the shape smaller
5. Game ends when the shape misses completely

## Features

- Perfect stacks highlighted in green
- Progressive speed increase
- Scrolling tower as you build higher
- High score tracking with chrome.storage
- Pink/purple gradient theme

## Controls

- Click button or press Space to drop

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Game interface
- `popup.css` - Styling with dark theme
- `popup.js` - Game logic
