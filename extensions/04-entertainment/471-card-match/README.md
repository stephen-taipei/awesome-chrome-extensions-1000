# Card Match

A classic card memory matching game Chrome extension.

## Features
- 4x4 grid with 8 pairs of symbols
- Flip cards to find matching pairs
- Move counter tracks your efficiency
- Best score saved locally
- Smooth flip animations

## How to Play
1. Click on a card to flip it
2. Click another card to find a match
3. Match all pairs with fewest moves
4. Try to beat your best score!

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
