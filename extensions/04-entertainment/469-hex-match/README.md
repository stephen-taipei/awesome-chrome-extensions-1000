# Hex Match

Match hexagonal tiles by swapping adjacent tiles to form patterns.

## Features
- Hexagonal grid layout
- Colorful tiles with symbols
- Swap adjacent tiles to match 3+
- High score persistence

## How to Play
1. Click a tile to select it
2. Click an adjacent tile to swap
3. Match 3 or more of the same color horizontally
4. Invalid swaps are reversed automatically

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
