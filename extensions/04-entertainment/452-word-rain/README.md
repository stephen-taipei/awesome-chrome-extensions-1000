# Word Rain

A typing game where words fall like rain - type them before they hit the ground!

## How to Play

1. Click "Start Game" to begin
2. Words will fall from the top of the screen
3. Type each word exactly to clear it
4. Score points based on word length (2 points per letter)
5. Game ends when any word reaches the bottom

## Features

- 20 different words to type
- Score based on word length
- High score tracking with chrome.storage
- Visual warning when words are near bottom
- Purple/violet dark theme

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Game interface
- `popup.css` - Styling with dark theme
- `popup.js` - Game logic
