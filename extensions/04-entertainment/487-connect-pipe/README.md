# Connect Pipe

A puzzle game where you rotate pipes to create a connected path.

## Features
- Click pipes to rotate them
- Connect start to end point
- Multiple pipe types (straight, corner, T, cross)
- Level progression saved with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Click on pipes to rotate them 90 degrees
2. Connect the path from start (top-left) to end (bottom-right)
3. All pipes in the path must align properly
4. Complete levels with fewer moves for better scores

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Pipe puzzle logic
