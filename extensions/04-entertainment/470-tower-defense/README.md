# Tower Defense

A simple tower defense mini-game where you place towers to stop enemies.

## Features
- Place towers to defend the path
- Enemies follow a winding path
- Earn gold by defeating enemies
- Progressive wave difficulty

## How to Play
1. Click "Place Tower" then click on the map
2. Each tower costs 50 gold
3. Click "Start Wave" to begin
4. Towers auto-attack nearby enemies
5. Don't let enemies reach the end!

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
