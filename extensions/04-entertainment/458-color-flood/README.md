# Color Flood

A Chrome extension game where you flood fill the board to make all cells the same color.

## Features
- 10x10 colorful grid
- 6 colors to choose from
- Limited moves challenge
- Win counter via chrome.storage.local
- Dark theme with teal gradient UI

## How to Play
1. Click a color button to flood fill from the top-left corner
2. The flood spreads to adjacent cells of the same color
3. Try to fill the entire board with one color within 25 moves

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
