# Block Breaker

Classic breakout-style paddle game where you destroy blocks with a bouncing ball.

## Features
- Mouse-controlled paddle
- Multiple rows of colorful blocks
- Progressive difficulty increase
- High score persistence

## How to Play
1. Move your mouse to control the paddle
2. Bounce the ball to break blocks
3. Clear all blocks to advance
4. Don't let the ball fall!

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
