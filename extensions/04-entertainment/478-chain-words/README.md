# Chain Words

Connect letters to form valid words!

## Features
- 4x4 letter grid
- Click letters to chain words
- Valid 3+ letter words score
- Used letters get replaced

## How to Play
1. Click letters to select them
2. Form valid English words
3. Submit to score points
4. Letters refresh for chains

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
