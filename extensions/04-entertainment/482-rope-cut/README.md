# Rope Cut

A physics-based puzzle game where you cut ropes to drop items into targets.

## Features
- Click to cut ropes and release items
- Physics-based falling mechanics
- Progressive levels with increasing difficulty
- Score and level persistence with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Click on ropes to cut them
2. Time your cuts to drop the item into the target
3. Each successful drop advances the level
4. Higher levels give more points

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Game logic with physics
