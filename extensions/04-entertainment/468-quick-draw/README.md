# Quick Draw

Draw the requested shape as quickly and accurately as possible before time runs out.

## Features
- Various shapes to draw (circle, square, triangle, line, X)
- Timer-based scoring (faster = more points)
- Shape recognition algorithm
- High score persistence

## How to Play
1. See the shape name at the top
2. Draw the shape on the canvas before time runs out
3. Faster completion earns more points
4. Keep drawing to increase your score

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
