# Laser Puzzle

Redirect lasers to targets using mirrors.

## Features
- Click mirrors to rotate them
- Fire laser to test your solution
- Multiple challenging levels
- Track puzzles solved

## How to Play
1. Click on mirrors to change their angle
2. Press "Fire Laser" to see the beam path
3. Guide the red laser to the green target
4. Advance to harder levels

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
