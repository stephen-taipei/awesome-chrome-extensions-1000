# Color Sort

Sort colored balls into matching tubes puzzle game.

## Features
- Sort balls by moving between tubes
- Progressive difficulty levels
- Move counter
- Satisfying ball animations

## How to Play
1. Click a tube to select the top ball
2. Click another tube to move it
3. Stack same-colored balls only
4. Complete when each tube has one color

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
