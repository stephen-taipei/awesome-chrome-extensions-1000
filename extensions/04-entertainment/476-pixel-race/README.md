# Pixel Race

A retro-style racing game with pixel graphics.

## Features
- Dodge oncoming cars
- Speed increases over time
- Pixel art aesthetics
- High score tracking

## How to Play
1. Use A/D or arrow keys to steer
2. Avoid red cars
3. Survive as long as possible
4. Press SPACE to restart

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
