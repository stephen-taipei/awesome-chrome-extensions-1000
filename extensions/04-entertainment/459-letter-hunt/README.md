# Letter Hunt

A Chrome extension game where you find hidden target letters in a grid.

## Features
- 6x6 letter grid
- Random target letter each round
- Score tracking with penalties for wrong clicks
- High score via chrome.storage.local
- Dark theme with yellow/gold gradient UI

## How to Play
1. Look at the target letter shown at the top
2. Click all cells containing that letter
3. Correct clicks earn 10 points, wrong clicks lose 5 points
4. Find all target letters to advance to the next round

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
