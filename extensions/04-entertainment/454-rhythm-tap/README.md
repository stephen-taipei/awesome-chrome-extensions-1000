# Rhythm Tap

A rhythm game where you tap colorful circles as they appear!

## How to Play

1. Click "Start Game" to begin
2. Colorful circles will appear on screen
3. Click/tap them quickly for higher scores
4. Build combos by hitting consecutive beats
5. Miss a beat and lose your combo
6. Game lasts 30 seconds

## Scoring

- **Perfect** (< 0.4s): 100 points
- **Good** (< 0.8s): 50 points
- **OK** (< 1.5s): 25 points
- Combo multiplier increases score!

## Features

- Colorful neon circles
- Combo system with multiplier
- Perfect/Good/Miss feedback
- High score tracking with chrome.storage
- Rainbow gradient dark theme

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Game interface
- `popup.css` - Styling with dark theme
- `popup.js` - Game logic
