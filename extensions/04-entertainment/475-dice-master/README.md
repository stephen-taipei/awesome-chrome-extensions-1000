# Dice Master

Roll dice to hit target numbers!

## Features
- Roll two dice to match target
- Streak bonus for consecutive hits
- Animated dice rolling
- Persistent score tracking

## How to Play
1. See the target number (2-12)
2. Click Roll Dice
3. Try to match the target sum
4. Build streaks for bonus points

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
