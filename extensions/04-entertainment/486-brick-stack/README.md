# Brick Stack

A tower building game where precision stacking is key.

## Features
- Moving brick must be dropped at the right time
- Overhanging parts are cut off
- Speed increases as tower grows
- High score tracking with chrome.storage.local
- Colorful gradient theme

## How to Play
1. Click "Drop Brick" or the canvas to drop
2. Align the moving brick with the one below
3. Misaligned parts get trimmed
4. Miss completely and it's game over
5. Build the tallest tower possible!

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Colorful theme styling
- popup.js - Stacking game logic
