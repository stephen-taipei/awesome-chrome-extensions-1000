# Bubble Burst

A fun bubble-popping Chrome extension game.

## Features
- Pop colorful bubbles to score points
- Smaller bubbles are worth more points
- Progressive difficulty - more bubbles spawn as you score higher
- High score tracking with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Click on bubbles to pop them
2. Smaller bubbles give more points
3. Clear all bubbles to spawn a new wave
4. Try to beat your high score!

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Game logic
