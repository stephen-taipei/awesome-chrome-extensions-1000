# Drop Merge

A merging puzzle game where you drop and combine same-colored items.

## Features
- Drop colored balls into the play area
- Same color and size balls merge into larger ones
- Maximum size balls disappear for bonus points
- High score tracking with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Move mouse to position the dropper
2. Click to drop the ball
3. Match same color and size balls to merge them
4. Merged balls grow larger
5. Don't let balls stack to the top!

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Game logic with merging mechanics
