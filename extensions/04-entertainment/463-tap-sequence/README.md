# Tap Sequence

Tap numbers or letters in the correct sequence order.

## Features
- Two modes: Numbers and Letters
- Progressive difficulty levels
- Tests memory and attention
- High score tracking

## How to Play
1. Select number or letter mode
2. Tap items in sequential order (1,2,3... or A,B,C...)
3. Complete sequences to advance levels
4. Wrong tap resets to level 1

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
