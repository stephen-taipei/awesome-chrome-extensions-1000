# Emoji Hunt

A fast-paced emoji finding game.

## Features
- Find target emojis hidden among distractors
- Timed gameplay (30 seconds)
- Bonus points for clearing all targets
- Penalty for wrong clicks
- High score tracking with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Click "Start Game" to begin
2. Look at the target emoji shown above the grid
3. Click all matching emojis in the grid
4. Find all targets for bonus points
5. Wrong clicks deduct points
6. Score as much as possible in 30 seconds

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Emoji hunt game logic
