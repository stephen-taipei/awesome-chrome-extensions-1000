# Word Stack

Stack letter blocks in the correct order to spell words.

## Features
- Click letters to stack them
- Spell the target word correctly
- Score points based on word length
- High score persistence

## How to Play
1. See the target word at the top
2. Click letters in order to spell it
3. Wrong order clears the stack
4. Clear button resets your selection

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
