# Symbol Match

A Chrome extension memory game where you match pairs of symbols.

## Features
- 4x4 grid with 8 symbol pairs
- Flip animation when revealing cards
- Move counter and best score tracking
- High score via chrome.storage.local
- Dark theme with purple gradient UI

## How to Play
1. Click a card to flip it and reveal the symbol
2. Click another card to find its match
3. Match all pairs with the fewest moves possible
4. Matched pairs stay revealed, mismatches flip back

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
