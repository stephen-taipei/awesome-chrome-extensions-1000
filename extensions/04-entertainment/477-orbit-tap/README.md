# Orbit Tap

Tap when the orbiting dot reaches the target!

## Features
- Simple one-button gameplay
- Speed increases with score
- Lives system
- High score tracking

## How to Play
1. Watch the pink dot orbit
2. Tap when it reaches the green target
3. Speed increases each hit
4. Miss 3 times and restart

## Installation
1. Open Chrome Extensions (chrome://extensions/)
2. Enable Developer Mode
3. Click "Load unpacked" and select this folder
