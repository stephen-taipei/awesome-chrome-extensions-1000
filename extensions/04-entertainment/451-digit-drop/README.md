# Digit Drop

A fast-paced typing game where numbers fall from the sky!

## How to Play

1. Click "Start Game" to begin
2. Three-digit numbers will fall from the top of the screen
3. Type the numbers before they reach the bottom
4. Each correct number scores 10 points
5. Game ends when any number reaches the bottom

## Features

- Progressive difficulty as you play
- High score tracking with chrome.storage
- Visual warning when digits are near the bottom
- Dark theme with neon aesthetics

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Game interface
- `popup.css` - Styling with dark theme
- `popup.js` - Game logic
