# Number Path

A Chrome extension game where you click on numbers in sequential order to create a path.

## Features
- Progressive difficulty with more numbers each level
- Visual path highlighting
- High score tracking via chrome.storage.local
- Dark theme with pink gradient UI

## How to Play
1. Click on numbers in order starting from 1
2. Follow the highlighted current number
3. Complete all numbers to advance to the next level

## Installation
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
