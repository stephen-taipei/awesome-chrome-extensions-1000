# Target Aim

A fast-paced target shooting game to test your aiming skills.

## Features
- Click on moving targets to score points
- Smaller targets give more points
- 30-second timed rounds
- High score tracking with chrome.storage.local
- Dark theme with gradient styling

## How to Play
1. Click "Start Game" to begin
2. Click on targets to shoot them
3. Smaller, faster targets = more points
4. Score as many points as possible in 30 seconds

## Installation
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Files
- manifest.json - Extension configuration
- popup.html - Game structure
- popup.css - Dark theme styling
- popup.js - Game logic with target movement
