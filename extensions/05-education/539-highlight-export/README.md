# Highlight Export

A Chrome extension to export highlights to text, markdown, or HTML format.

## Features

- Capture text selections as highlights
- Export in multiple formats (Plain Text, Markdown, HTML)
- Option to include source URL and date
- Group highlights by source
- Live export preview
- Copy to clipboard or download file

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Select text on any webpage
2. Click the extension icon
3. Click "Capture Selection"
4. Choose export format and options
5. Copy or download your highlights

## Permissions

- `storage`: Save highlights locally
- `activeTab`: Access selected text on current tab
