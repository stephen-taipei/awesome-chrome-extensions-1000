# Note Taker

A Chrome extension for quick study notes while browsing.

## Features

- Create notes with optional titles
- Add tags for organization
- Search notes by title, content, or tags
- View recent notes list
- Delete notes easily
- Track total note count

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Enter a title (optional)
3. Write your note content
4. Add tags by typing and pressing Enter
5. Click "Save Note"

## Permissions

- `storage`: Save notes locally
