# Quiz Generator

A Chrome extension to generate quizzes from content for self-testing.

## Features

- Create custom quizzes with multiple choice questions
- Support for 2-4 options per question
- Take quizzes with immediate feedback
- View correct answers after selection
- Score tracking and percentage display
- Quiz history to track progress
- Retake quizzes for practice

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Create tab: Add questions with options and correct answers
3. Save quiz with a name
4. Quiz tab: Select a quiz and start
5. History tab: View past quiz attempts

## Permissions

- `storage`: Save quizzes and history
- `activeTab`: Future feature for auto-generating questions
