# Article Highlighter

A Chrome extension to highlight and save key passages from articles for later review.

## Features

- Multiple highlight colors (yellow, green, blue, pink, orange)
- Save selected text with one click
- View all saved highlights in popup
- Delete individual highlights
- Track highlight count
- Persists highlights across sessions

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Select text on any webpage
2. Click the extension icon
3. Choose a highlight color
4. Click "Highlight Selection" to save
5. View saved highlights in the popup

## Permissions

- `storage`: Save highlights locally
- `activeTab`: Access selected text on current tab
