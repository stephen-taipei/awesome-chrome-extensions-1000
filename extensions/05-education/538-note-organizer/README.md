# Note Organizer

A Chrome extension to organize study notes into folders and categories.

## Features

- Create folders for different subjects
- Add notes with titles and content
- Navigate between folders and notes
- Search across all notes
- Track folder and note counts
- Delete folders and notes

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Create folders for different subjects
3. Click a folder to open it
4. Add notes with title and content
5. Use search to find notes across folders

## Permissions

- `storage`: Save notes locally
