# Concept Mapper

A Chrome extension for creating simple concept maps for visual learning.

## Features

- Create hierarchical concept maps
- Add concepts with parent relationships
- Optional relation labels between concepts
- Visual tree-style display
- Save and load maps
- Delete concepts (cascades to children)

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Enter a concept name
3. Optionally select a parent concept
4. Add a relation label (e.g., "leads to", "contains")
5. Click "Add Concept"
6. Build your map and save it

## Permissions

- `storage`: Save concept maps locally
