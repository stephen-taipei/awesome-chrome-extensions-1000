# Speed Reader

A Chrome extension for speed reading training using RSVP (Rapid Serial Visual Presentation) technique.

## Features

- RSVP speed reading display
- Adjustable reading speed (100-1000 WPM)
- Variable chunk size (1-3 words)
- Play/pause and navigation controls
- Progress tracking
- Estimated reading time
- Saves preferred speed

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Select text on any webpage
2. Click the extension icon
3. Click "Load Selection"
4. Adjust speed and chunk size
5. Press play to start reading
6. Use navigation buttons to skip

## Permissions

- `storage`: Save speed preferences
- `activeTab`: Access selected text on current tab
