# Flashcard Maker

A Chrome extension to create flashcards from selected text for studying.

## Features

- Create flashcard decks
- Add cards with front (question) and back (answer)
- Use selected text from page as answer
- Study mode with flip animation
- Navigate through cards
- Shuffle cards for random study
- Manage decks and delete cards

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Create tab: Enter deck name, front (question), and back (answer)
3. Use "Use Selection as Answer" to grab selected text
4. Study tab: Select a deck and study with flip cards
5. Manage tab: View, edit, or delete cards and decks

## Permissions

- `storage`: Save flashcard decks
- `activeTab`: Access selected text on current tab
