# Reading List

A Chrome extension to organize and manage your reading materials.

## Features

- Add current page to reading list
- Separate tabs for unread and read items
- Sort by newest, oldest, or title
- Mark items as read/unread
- Quick open from list
- Track reading statistics

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Navigate to an article or page you want to save
2. Click the extension icon
3. Click "Add Current Page"
4. Mark as read when finished
5. Sort and filter your list

## Permissions

- `storage`: Save reading list locally
- `tabs`: Access current tab information
