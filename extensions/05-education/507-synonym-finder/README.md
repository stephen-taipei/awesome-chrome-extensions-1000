# Synonym Finder

A Chrome extension to find synonyms for words and expand vocabulary.

## Features

- **Synonym Lookup**: Find synonyms for common words
- **Related Words**: Discover words with similar meanings
- **Word Definitions**: Understand word meanings in context
- **Example Sentences**: See words used in context
- **Save Words**: Build a personal vocabulary list
- **Search History**: Quick access to recent searches

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. Enter a word in the search box
3. View synonyms, related words, and examples
4. Click on any synonym to look it up
5. Star synonyms to save them to your list
6. Access saved words and history at the bottom

## Word Categories

The extension includes synonyms for:
- Common adjectives (happy, sad, big, small)
- Quality words (good, bad, beautiful)
- Speed words (fast, slow)
- Important verbs (think, say)

## File Structure

- `manifest.json` - Extension configuration
- `popup.html` - Main popup interface
- `popup.css` - Styles with dark theme
- `popup.js` - Synonym lookup logic
- `README.md` - Documentation

## Permissions

- `storage` - Save words and search history
