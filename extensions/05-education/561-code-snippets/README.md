# Code Snippets

A Chrome extension to save and organize code snippets for quick reference.

## Features

- Save code snippets with title, language, and tags
- Support for multiple programming languages
- Search snippets by title, content, or tags
- Filter by programming language
- Copy snippets to clipboard with one click
- Persistent storage using Chrome's storage API
- Dark theme interface

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this extension folder

## Usage

1. Click the extension icon to open the popup
2. Enter a title for your snippet
3. Select the programming language
4. Paste or type your code
5. Add optional tags for organization
6. Click "Save Snippet"
7. Use search and filter to find saved snippets
8. Click "Copy" to copy code to clipboard

## Storage

All snippets are stored locally using Chrome's storage API.

## Permissions

- `storage`: For saving snippets locally
