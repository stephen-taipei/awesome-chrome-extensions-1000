# Idiom Explorer

A Chrome extension to learn common idioms and their meanings.

## Features

- **Idiom Database**: Collection of 18+ common English idioms
- **Category Filters**: Browse by Time, Money, Animals, Body, or All
- **Search Function**: Find idioms by text or meaning
- **Random Idiom**: Discover new expressions randomly
- **Audio Pronunciation**: Listen to idioms spoken aloud
- **Favorites System**: Save idioms for later review
- **Copy to Clipboard**: Share idioms easily

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. View the featured idiom with meaning, example, and origin
3. Click "Random Idiom" for a new expression
4. Use category tabs to filter idioms
5. Search for specific idioms
6. Star idioms to add to favorites
7. Click the speaker icon to hear pronunciation

## Categories

- **Time**: Time-related idioms
- **Money**: Financial expressions
- **Animals**: Animal-based idioms
- **Body**: Body part expressions
- **All**: Complete collection

## Each Idiom Includes

- The idiom expression
- Meaning explanation
- Example sentence
- Historical origin

## File Structure

- `manifest.json` - Extension configuration
- `popup.html` - Main popup interface
- `popup.css` - Styles with dark theme
- `popup.js` - Idiom data and interaction logic
- `README.md` - Documentation

## Permissions

- `storage` - Save favorite idioms
