# Study Planner

A Chrome extension to plan and organize your study sessions.

## Features

- Schedule study sessions by date
- Set start and end times
- Add subject and topic focus
- Priority levels (High, Normal, Low)
- Navigate between days
- Mark sessions as complete
- Track planned hours and completion stats

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Select a date using navigation arrows
3. Enter subject, times, and optional topic
4. Set priority level
5. Add session to schedule
6. Mark complete when finished

## Permissions

- `storage`: Save study schedule locally
