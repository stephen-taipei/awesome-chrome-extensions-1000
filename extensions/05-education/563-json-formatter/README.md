# JSON Formatter

A Chrome extension to format, validate, and minify JSON data.

## Features

- Format JSON with customizable indentation
- Minify JSON to reduce size
- Validate JSON syntax
- Syntax highlighting for output
- Sort keys alphabetically
- Copy formatted output to clipboard
- Display size and key count statistics
- Dark theme interface

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this extension folder

## Usage

1. Click the extension icon to open the popup
2. Paste your JSON in the input area
3. Click "Format" to beautify JSON
4. Click "Minify" to compress JSON
5. Click "Validate" to check syntax
6. Use "Copy" to copy the output
7. Adjust indent size and sort options as needed

## Options

- **Indent Size**: 2 spaces, 4 spaces, or tab
- **Sort Keys**: Alphabetically sort object keys

## Storage

User preferences are stored locally using Chrome's storage API.

## Permissions

- `storage`: For saving user preferences
