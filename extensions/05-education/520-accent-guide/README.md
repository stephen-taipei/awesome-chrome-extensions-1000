# Accent Guide

A Chrome extension to learn pronunciation accents and dialects from different regions.

## Features

- **Three Languages**: English, Spanish, French
- **Multiple Accents Per Language**: Regional variations and dialects
- **Key Features**: Distinctive pronunciation characteristics
- **Example Words**: Words with phonetic pronunciations
- **Pronunciation Tips**: Practical advice for each accent
- **Audio Practice**: Listen to example words
- **Save Accents**: Build your accent collection
- **Compare Mode**: Quickly switch between accents

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. Select a language (English, Spanish, French)
3. Choose an accent tab to explore
4. Read features and tips for each accent
5. Click example words to hear pronunciation
6. Practice listening with random words
7. Save favorite accents for later reference

## Accents Included

### English (3 accents)
- American (General) - United States
- British (RP) - United Kingdom
- Australian - Australia

### Spanish (3 accents)
- Castilian - Spain (Central)
- Latin American - Latin America
- Mexican - Mexico

### French (3 accents)
- Parisian - France (Paris)
- Québécois - Canada (Quebec)
- Belgian - Belgium
