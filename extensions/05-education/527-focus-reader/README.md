# Focus Reader

A Chrome extension to remove distractions while reading for better focus.

## Features

- Focus mode for distraction-free reading
- Adjustable text width, font size, and line height
- Three themes: Dark, Light, and Sepia
- Hide images, sidebars, ads, and comments
- Settings persist across sessions

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Navigate to an article you want to read
2. Click the extension icon
3. Adjust settings to your preference
4. Click "Enable Focus Mode"
5. Enjoy distraction-free reading

## Permissions

- `storage`: Save reading preferences
- `activeTab`: Apply focus mode to current tab
- `scripting`: Inject focus mode styles
