# Bookmark Annotator

A Chrome extension to add annotations and notes to your bookmarks.

## Features

- Add annotations to current page
- Categorize bookmarks (Important, Reference, Research, To Read)
- Filter bookmarks by category
- Quick open annotated bookmarks
- Edit existing annotations
- Delete annotations

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Navigate to a page you want to annotate
2. Click the extension icon
3. Write your annotation
4. Select a category (optional)
5. Click "Save Annotation"

## Permissions

- `storage`: Save annotations locally
- `tabs`: Access current tab information
