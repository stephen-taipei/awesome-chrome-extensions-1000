# Outline Maker

A Chrome extension to create outlines from articles for better comprehension.

## Features

- Extract headings from web pages automatically
- Manually add outline items at different levels
- Three hierarchical levels with visual distinction
- Copy outline to clipboard in text format
- Save outlines for later reference
- Load and edit saved outlines

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Navigate to an article
2. Click the extension icon
3. Click "Extract Page Headings" to auto-generate outline
4. Manually add items by selecting level and entering text
5. Save or copy your outline

## Permissions

- `storage`: Save outlines locally
- `activeTab`: Extract headings from current page
