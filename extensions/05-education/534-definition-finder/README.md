# Definition Finder

A Chrome extension to highlight terms and save definitions for vocabulary building.

## Features

- Capture selected text as vocabulary terms
- Add custom definitions
- Categorize terms by subject
- Search through vocabulary
- Filter by category
- Track vocabulary count

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Select a term on any webpage
2. Click the extension icon
3. Click "Capture Selected Term"
4. Enter the definition
5. Select a category (optional)
6. Save to your vocabulary list

## Permissions

- `storage`: Save vocabulary locally
- `activeTab`: Access selected text on current tab
