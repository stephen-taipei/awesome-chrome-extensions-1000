# Progress Tracker

A Chrome extension to track your learning progress across subjects.

## Features

- Add subjects with total topic count
- Track completed topics per subject
- Visual progress bars per subject
- Overall progress circle display
- Day streak tracking
- Total study days counter

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Add a subject with total number of topics
3. Use +1/-1 buttons to update progress
4. Watch your overall progress grow
5. Maintain your study streak

## Permissions

- `storage`: Save progress data locally
