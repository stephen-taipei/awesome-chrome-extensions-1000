# Phrase Builder

A Chrome extension to learn common phrases and expressions.

## Features

- **Four Categories**: Everyday, Business, Academic, Social
- **Complete Phrase Info**: Meaning, example, and usage context
- **Audio Pronunciation**: Hear phrases spoken
- **Fill-in-the-Blank Practice**: Interactive quiz mode
- **Save Phrases**: Build your phrase collection
- **Navigation**: Browse or get random phrases

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. Select a phrase category
3. Browse phrases or click Random
4. Practice with fill-in-the-blank exercises
5. Save favorite phrases for later
