# Vocabulary Tracker

A Chrome extension to track learned words and monitor vocabulary growth.

## Features

- **Word Tracking**: Add words with meanings and categories
- **Statistics**: Total words, weekly, monthly, and streak counts
- **Daily Goals**: Set and track daily word learning goals
- **Progress Bar**: Visual goal completion indicator
- **Weekly Chart**: See your learning pattern over the week
- **Category Filtering**: Filter words by category
- **Streak System**: Maintain learning streaks

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. Add new words with their meanings
3. Assign words to categories
4. Track your daily goal progress
5. View weekly learning chart
6. Maintain your streak by learning daily

## Categories

- **General**: Everyday vocabulary
- **Academic**: Educational/scholarly words
- **Business**: Professional terminology
- **Technical**: Specialized/technical terms

## Statistics Tracked

- Total words learned
- Words added this week
- Words added this month
- Current day streak

## File Structure

- `manifest.json` - Extension configuration
- `popup.html` - Main popup interface
- `popup.css` - Styles with dark theme
- `popup.js` - Tracking logic and data management
- `README.md` - Documentation

## Permissions

- `storage` - Save vocabulary data
