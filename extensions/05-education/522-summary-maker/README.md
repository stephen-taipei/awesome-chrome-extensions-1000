# Summary Maker

A Chrome extension to summarize selected text from web pages for quick review.

## Features

- Three summary lengths: short, medium, and long
- Intelligent sentence extraction based on importance
- Copy summary to clipboard
- Save summaries for later reference
- View and manage saved summaries

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Select text on any webpage
2. Click the extension icon
3. Choose desired summary length
4. Click "Summarize Selection"
5. Copy or save the generated summary

## Permissions

- `storage`: Save summaries locally
- `activeTab`: Access selected text on current tab
