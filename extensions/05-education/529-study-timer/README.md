# Study Timer

A Chrome extension implementing the Pomodoro technique for productive studying.

## Features

- Pomodoro timer with focus, short break, and long break modes
- Visual progress ring
- Customizable duration for each mode
- Session tracking (daily and total)
- Desktop notifications when timer completes
- Settings persist across sessions

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Select a mode (Focus, Short Break, Long Break)
3. Adjust durations in settings if needed
4. Click "Start" to begin
5. Take breaks when prompted

## Permissions

- `storage`: Save settings and statistics
- `alarms`: Background timer functionality
- `notifications`: Alert when timer completes
