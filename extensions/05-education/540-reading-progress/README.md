# Reading Progress

A Chrome extension to track reading progress across articles and books.

## Features

- Track current page being read
- Add books with page progress
- Visual progress bars
- Mark items as completed
- View completed reading history
- Track total pages read statistics

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Click the extension icon
2. Click "Track Current Page" to add an article
3. Or add a book with title and page count
4. Update progress as you read
5. Items auto-complete when finished

## Permissions

- `storage`: Save reading progress locally
- `tabs`: Access current tab information
