# Verb Conjugator

A Chrome extension to practice verb conjugations in multiple languages.

## Features

- **Three Languages**: Spanish, French, and Italian
- **Three Tenses**: Present, Past, and Future
- **Full Conjugation Tables**: All six person forms
- **Practice Mode**: Test your conjugation skills
- **Common Verbs**: Quick access to frequently used verbs
- **Search Function**: Look up any verb in the database

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select this extension's directory

## Usage

1. Click the extension icon to open the popup
2. Select your target language
3. Choose a tense (Present, Past, Future)
4. Enter a verb or click a common verb chip
5. View the full conjugation table
6. Click "Start Practice" to test yourself

## Languages & Verbs

### Spanish
- hablar (to speak), comer (to eat), vivir (to live)
- ser (to be), tener (to have)

### French
- parler (to speak), manger (to eat)
- etre (to be), avoir (to have)

### Italian
- parlare (to speak), mangiare (to eat)
- essere (to be), avere (to have)

## Practice Mode

- Random verb and tense combinations
- Type the correct conjugation
- Instant feedback
- Score tracking
