# Citation Helper

A Chrome extension to format citations quickly in APA, MLA, and Chicago styles.

## Features

- Support for multiple source types (web, book, journal, video)
- Auto-fill from current page
- Three citation styles: APA, MLA, Chicago
- Copy citation to clipboard
- Save citations for later reference
- Manage saved citations

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder

## Usage

1. Navigate to a source you want to cite
2. Click the extension icon
3. Click "Auto-fill from Page" or enter details manually
4. Select your preferred citation style
5. Copy the generated citation

## Permissions

- `storage`: Save citations locally
- `tabs`: Access current tab for auto-fill
